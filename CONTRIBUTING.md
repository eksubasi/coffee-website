# Contributing

## Branch naming
Each member uses their own prefix:

| Member | Prefix |
| --- | --- |
| Zeynep Altundal (M1) | `zeynep/` |
| Melike Yildirim (M2) | `melike/` |
| Betul Eken (M3) | `betul/` |
| Yesim Tosun (M4) | `yesim/` |
| Emir Kerem Subasi (M5) | `emir/` |
| Ahmet Efe (M6) | `ahmet/` |

Format: `<name>/KAN-xx-short-name`
Example: `melike/KAN-22-product-model`

Create your branch from `main` when you start a ticket:
`git checkout -b melike/KAN-22-product-model`

## Commits
Format: `KAN-xx: message`
Example: `KAN-22: add Product model`

## Pull requests
- PR title starts with the Jira key, e.g. `KAN-22: Product model`
- At least 1 approving review is required
- Merge with **squash merge** into `main`
